## Not included, on purpose

- No NVIDIA, AMD or Intel driver binary, and no `PresentMonAPI2.dll`: each is loaded from the user's own installation.
- No ADLX header-derived source: AMD's SDK licence permits object-code distribution only, so bindings are generated at build time from the user's SDK checkout.
- No copy of NVIDIA Profile Inspector and no `Reference.xml`: the tool is optional and user-supplied; `Reference.xml` can be loaded at run time from the user's own copy.
- The `.nip` test fixtures in `nvidia/fixtures/` were written for this project to match the format; they are not copied from anyone's exports.
